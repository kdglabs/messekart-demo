# Messekart – demo

Klikkbar demo av et digitalt messekart for TCG-messer, laget av **KDG Labs**.

> Dette er kun en demo. Alle data er fiktive eksempeldata (Oslo TCG Show) – selgere, bord, kontaktinfo og kort finnes ikke i virkeligheten.

**Live demo:** https://kdglabs.github.io/messekart-demo/

## Innhold

- `index.html` – gjeldende versjon (v3.1), helt selvstendig (all CSS/JS er inline).
- `v1.html`, `v2.html`, `v3.html` – eldre versjoner.
- `src/` – kildefiler. Bygg `index.html` på nytt med:

  ```sh
  python3 src/build.py
  ```
